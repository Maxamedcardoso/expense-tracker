# Pennywise Expense Tracker

App fudud oo lagu diiwaangeliyo laguna maamulo kharashyada maalinlaha ah. Waxaa lagu dhisay HTML, CSS iyo JavaScript, xogtana browser-ka ayuu ku kaydiyaa isagoo adeegsanaya `localStorage`.

## Waxyaabaha uu qabto

- Ku dar kharash cusub oo leh magac, lacag, qayb iyo taariikh.
- Wax ka beddel ama tirtir kharash jira.
- Si toos ah u cusboonaysii wadarta kharashka iyo miisaaniyadda hadhay.
- Xogta ku hay browser-ka si ay u sii jirto marka bogga dib loo furo.
- Muuji loading yar inta xogta la soo celinayo.

## Sida loo furo

1. Fur faylka `index.html` browser-ka, ama isticmaal VS Code Live Server.
2. Buuxi magaca kharashka, lacagta, qaybta iyo taariikhda.
3. Riix **Add expense** si aad u geliso.
4. Adeegso **Edit** si aad xogta u beddesho, ama **Delete** kadibna xaqiiji tirtirista.

App-ku ma laha build ama package-install tallaabooyin; browser casri ah ayaa ku filan. Font-ka DM Sans waxaa laga soo qaataa Google Fonts marka internet jiro; haddii kale fallback font ayaa shaqaynaya.

## Faylasha mashruuca

- `index.html` — qaab-dhismeedka bogga iyo foomka.
- `style.css` — muuqaalka iyo habaynta shaashadaha kala duwan.
- `script.js` — ku darista, wax-ka-beddelka, tirtirista iyo cusboonaysiinta wadarta.
- `storage.js` — akhrinta iyo kaydinta kharashyada ee `localStorage`.

## Kaydinta xogta

Kharashyada waxaa lagu kaydiyaa furaha `pennywise-expenses-v1` ee `localStorage`-ka browser-ka. Xogtu waxay ku xiran tahay browser-ka iyo meesha app-ka laga furay; browser ama kombiyuutar kale si toos ah uma arko.

Si aad u tirtirto xogta app-ka, fur Developer Tools ee browser-ka, gal **Application/Storage → Local Storage**, ka dooro meesha app-ka, kadibna ka tirtir furaha `pennywise-expenses-v1`.

## Miisaaniyadda bilowga ah

Qiimayaasha bilowga ah waxaa lagu dejiyey `index.html`: wadarta kharashku waa `$1,248.50`, miisaaniyadduna waa `$2,000.00`. Kharashyada aad app-ka ku darto ayaa lagu daraa wadartaas; miisaaniyadda waxaa laga jarayaa wadarta cusub.
